# v0.2.0 — Runtime model switching, member definitions, quotas, and exact fork identity

- Switch a member's provider/model/reasoning effort from the activity panel while it is idle; the new route applies from the next model step and survives a cold resume.
- Discover Markdown member definitions (workspace `.agents/agents`, `~/.dsh/agents`, `~/.agents/agents`) with YAML frontmatter, map their tools, skills, and MCP servers to a member allowlist, and add members by definition name.
- Give every member a task and token quota (default 5 tasks / 200,000,000 tokens); on reaching either limit the member becomes `exhausted`, writes a handover document, and notifies the captain.
- Make team identity exact: a fork is an independent root session with its own team and no inherited captain view, while same-workspace team names stay unique.
- Baseline: Harness `0.2.2-rc.1`. Old `team.json` files keep loading; missing quota fields mean unlimited.

## 中文

- 活动面板可直接切换空闲成员的 provider/model/reasoning effort，新路由从下一个模型 step 生效，并在冷恢复后保持。
- 发现三处目录中的 Markdown 成员定义（YAML frontmatter），把工具、技能、MCP 映射为成员 allowlist，并可按定义名创建成员。
- 每个成员有任务与 Token 配额（默认 5 个任务 / 2 亿 Token），任一达到即进入 `exhausted`、写交接文档并通知队长。
- 团队身份精确化：fork 是独立根会话、拥有自己的团队且不继承父队视图；同工作区团队名保持唯一。
- 基线为 Harness `0.2.2-rc.1`；旧 `team.json` 可继续加载，缺失配额字段视为不限制。

## Install

In **Plugins → Add plugin**, enter `@nanmicoder/dsh-agent-teams@0.2.0`. For a CLI-managed profile, run:

```sh
dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.2.0
```

The recommended host is Harness `0.2.2-rc.1`. See the [tested matrix](../compatibility.json).
